# RemindMe

A local-first Windows reminder app built with Electron.

## Features

- Quick add reminders
- Due dates and time
- Priority levels
- Repeat rules
- Desktop notifications and sound alerts
- Edit, snooze, complete, and delete reminders
- Local storage on the device

## Install

```powershell
npm install
```

## Run

```powershell
npm run start
```

## Build

```powershell
npm run dist
```
