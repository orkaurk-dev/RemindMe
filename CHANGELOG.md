# Changelog

## v0.2.0
- Added editable reminders.
- Added repeat rules: daily, weekly, monthly.
- Added notification actions for open, done, and snooze.
- Added reminder sound alerts.
- Added single-instance Windows behavior.
- Improved packaging and shortcut setup.

## v0.1.0
- Initial Windows desktop release of RemindMe.
- Quick add reminders with due dates and priorities.
- Search, filtering, and local storage.
- First packaged Windows installer.
